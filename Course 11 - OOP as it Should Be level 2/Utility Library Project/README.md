# 🛠️ Utility Library Project (C++)

A comprehensive C++ Object-Oriented Utility Library (`clsUtility`) that provides essential helper functions for random generation, string manipulation, array shuffling, date swapping, and basic text encryption.

Designed as part of **Course 11 (OOP Applications)** with a strong focus on **Clean Code**, **Type Safety**, and **OOP Principles**.

---

## ✨ Features

- 🎲 **Random Generation:** Generate numbers, characters, words, and unique multi-segment security keys.
- 🔄 **Generic Swapping (`Overloading`):** Support for swapping integers, doubles, strings, and custom `clsDate` objects.
- 🔀 **Array Manipulations:** Fill and shuffle arrays containing numbers, words, or security keys.
- 🔒 **Text Encryption (Caesar Cipher):** Encrypt and decrypt strings securely using custom key offsets.
- 📐 **Formatting Utilities:** Built-in tab formatting methods using clean C++ `std::string` constructors.
